> Расширение для Visual Studio Code, позволяющее собирать CMake-проект, запускать тесты и визуализировать статистику прямо в терминале.

## ✨ Возможности
- [x] Сборка и тестирование по горячей клавише `Ctrl+Alt+C`.
- [x] Остановка цепочки команд при ошибке конфигурации или сборки (использование `&&`).
- [x] **Сбор статистики:** парсинг JUnit XML от `ctest` и сохранение истории запусков.
- [x] **Визуализация:** вывод цветного ASCII-графика (процент успеха) прохождения тестов прямо в терминал.
- [x] Подсчет пройденных, проваленных тестов и общего процента успеха.

## 🚀 Быстрый старт
1. Откройте в VS Code проект, содержащий файл `CMakeLists.txt`.
2. Нажмите `Ctrl+Alt+C` (или вызовите команду `CMake: Build & Test` из палитры команд).
3. В терминале выполнятся команды сборки, тестов (`ctest`), а затем появится цветная статистика и график.

<details>
<summary>💻 Как установить расширение (нажмите, чтобы развернуть)</summary>

**Для пользователей (сборка `.vsix`):**
`npm run package`
`code --install-extension cmake-build-test-0.0.1.vsix`

**Для разработчиков (из исходников):**
`git clone https://github.com/ваш-ник/cmake-build-test.git`
`cd cmake-build-test`
`npm install`
`npm run compile`
Откройте папку в VS Code и нажмите `F5` для запуска в режиме отладки.
