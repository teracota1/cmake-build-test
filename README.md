# CMake Build & Test

Расширение для Visual Studio Code, которое собирает CMake-проект, запускает тесты и показывает статистику прохождения тестов в терминале.

## Возможности
- Сборка проекта и запуск тестов по горячей клавише `Ctrl+Alt+C`.
- Остановка сборки при возникновении ошибок (использование `&&`).
- Сбор статистики (парсинг JUnit XML от `ctest`) и сохранение истории.
- Вывод цветного графика прохождения тестов прямо в терминал.

## Как пользоваться
1. Откройте в VS Code папку с проектом, где есть файл `CMakeLists.txt`.
2. Нажмите `Ctrl+Alt+C` (или выберите команду `CMake: Build & Test` в палитре команд).
3. В терминале выполнятся команды сборки и тестов, после чего появится цветной график.

Чтобы собрать плагин в файл `.vsix` для установки, выполните:
`npm run package`
Затем установите его через VS Code (Расширения -> Установить из VSIX).
