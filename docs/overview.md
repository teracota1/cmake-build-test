# Общее описание решения

## Назначение
**CMake Build & Test** — это расширение для Visual Studio Code, которое автоматизирует процесс сборки проектов на C/C++, запуск тестов и сбор статистики.

## Решаемая проблема
Разработчику важно видеть историю тестирования. Плагин решает это, автоматически собирая результаты и отображая их в виде графика. Помимо этого, он избавляет от рутины, объединяя команды `cmake` и `ctest` в одну кнопку.

## Как работает плагин
1. Плагин получает активный терминал VS Code.
2. Чтобы узнать, в какой папке находится пользователь (так как VS Code не предоставляет прямого доступа к текущей директории терминала), плагин отправляет в терминал команду `pwd` с перенаправлением вывода во временный файл.
3. Плагин читает этот файл, получает абсолютный путь к папке и проверяет наличие файла `CMakeLists.txt`.
4. Если файл найден, запускается сборка и тестирование. `ctest` генерирует JUnit XML файл.
5. Плагин парсит XML, сохраняет статистику в глобальное хранилище и выводит цветной ASCII-график прямо в терминал.

## Требования
- Операционная система: Windows, Linux или macOS.
- Установленный CMake (версия 3.20+) и Node.js.
- Наличие файла `CMakeLists.txt` в папке, в которой вы находитесь в терминале.

## Используемые технологии
- **TypeScript** — язык разработки.
- **VS Code API** — для создания команд, работы с терминалом и файловой системой.
- **Node.js (child_process, fs)** — для асинхронного запуска сборки в фоне и чтения временных файлов.
