# Общее описание решения

## Назначение
**CMake Build & Test** — это расширение для Visual Studio Code, которое автоматизирует процесс сборки проектов на C/C++, запуск тестов и сбор статистики.

## Решаемая проблема
Разработчику важно видеть историю тестирования. Плагин решает это, автоматически собирая результаты и отображая их в виде графика. Помимо этого, он избавляет от рутины, объединяя команды `cmake` и `ctest` в одну кнопку.

## Архитектура
1. **Сборка:** Плагин запускает `cmake` и `ctest` через встроенный терминал VS Code.
2. **Сбор данных:** `ctest` генерирует JUnit XML файл, который затем парсится плагином с помощью регулярных выражений.
3. **Хранение:** Статистика сохраняется локально в JSON-файл в глобальном хранилище VS Code.
4. **Визуализация:** Текст графика записывается во временный файл и выводится в терминал через Node.js. Это позволяет сохранить ANSI-цвета (в обход искажений оболочки Bash) и показать цветной график прямо в консоли.

## Требования
- Операционная система: Windows, Linux или macOS.
- Установленный CMake (версия 3.20+) и Node.js.
- Наличие файла `CMakeLists.txt` в корне открытого проекта.

## Используемые технологии
- **TypeScript** — язык разработки.
- **VS Code API** — для создания команд, работы с терминалом и файловой системой.
- **Node.js (child_process)** — для асинхронного запуска сборки в фоне.
